

adesso passiamo al pannello tratte.
dobbiamo solo creare il tasto aggiungi 
per la creazione delle tratte ci sono due end point diversi:
- tratta/crea che crea una tratta porto-porto quindi bisogna scegliere un porto di partenza tra quelli presenti nel database e uno di arrivo. in questo caso il playload da mandare è il seguente:
{
  "id": "string",
  "porto_partenza": "string",
  "porto_arrivo": "string",
  "distanza_miglia": 0
}
dove id deve avere la segeunte forma: "ABC - DEF"
dove ABC sono le prime tre lettere del porto di partenza e DEF sono le prime tre lettere del porto di arrivo, distanza_miglia passalo come null
- tratta/crea_multi è un endpoint che consente di creare una tratta con porti intermendi e accetta il seguente playload:
{
  "id": "string",
  "porti": [
    "string"
  ],
  "distanza_miglia": 0
}
anche qui l'id della tratta deve essere generato come nel caso precedente aggiungendo i porti intermendi al centro:
ABC - DEF - GHI - ... - XYZ
in entrambi i casi i porti devono essere passati come nome e non come id
